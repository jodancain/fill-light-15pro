# 开发计划

**v0.2 · 2026-11-17 · 配套 [规格书](规格书.md) v0.1**

这份计划说明补光灯分几步做、每一步交什么、怎样才算过关。v0.1 是立项时的版本；读完苹果官方尺寸图和几份芯片规格书后有 7 处修正（见规格书第 3 节），这里已按修正后的方案更新。

## 1 为什么做

要验证的是一整条硬件开发流程：需求 → 选型 → 原理图 → PCB → 结构 → 固件 → 下单 → 装配 → 测试。只用脚本生成图纸、不做实物，很多问题暴露不出来，要真正下单、装配、上电才会出现。补光灯是一个小而完整的产品，适合把这条路真实走一遍。

成功有两层：

1. **产品**：实测指标达到规格，亮度好于主流口袋补光灯。
2. **流程**：每道闸门都有记录，最后能说清哪些环节靠得住、哪些要改。

## 2 闸门

每个阶段结束时过一道闸门，不过不往下走。

| 闸门 | 产出 | 通过条件 |
|---|---|---|
| G0 规格 | 规格书、机电接口表、风险清单 | 每条指标可测、有参照；需求方确认 |
| G1 选型与计算 | 硬件需求、系统架构说明书、硬件架构设计书（含选型依据和预算） | 关键结论有规格书页码依据；独立复核没有未决的严重问题；需求方确认 |
| G2 四个实验 | 实验记录 | 见 [实验与采购清单](实验与采购清单.md) |
| G3 原理图 | 脚本生成的原理图；逐芯片对照规格书的检查表 | 电气规则检查 0 错误；检查表逐项通过；独立复核 |
| G4 PCB | 三块板的工程和下单文件 | 100% 布通；设计规则检查 0 错误；原理图与板图一致；物料清单位号与坐标文件一致；关键器件摆位检查通过；板厂审核无阻断项 |
| G5 结构 | 模型、试片、整套打印件 | 装配干涉检查通过；试片实配通过；整机装得上 |
| G6 固件 | 工程和单元测试 | 单元测试全过；上板后自检通过 |
| G7 装配上电 | 上电记录 | 按检查表逐步上电，各路电压和保护动作正常 |
| G8 实测 | 测试报告 | 实测对照硬件需求逐条判定 |
| G9 复盘 | 复盘报告 | 流程指标齐全，列出要带回其他项目的改动 |

G3、G4、G5、G6 在 G1 冻结接口后并行；G2 等物料期间不停工。

## 3 四个实验（G2）

画电路板之前先做，都很便宜，用来消除最大的不确定。步骤和判定见 [实验与采购清单](实验与采购清单.md)。

| 实验 | 要回答的问题 |
|---|---|
| 实验 1 散热假件 | 散热片不开风扇能带走多少瓦；开风扇能不能带走 20 W 灯的热 |
| 实验 2 对标灯实测 | 主流口袋灯实际有多亮，目标是不是真的明显更好 |
| 实验 3 电芯和风扇对手机的影响 | 钢壳电芯和风扇磁铁会不会影响指南针、防抖、信号；外形会不会入镜 |
| 实验 4 打印试片 | 壳架、电池仓、取景禁入区在实物上对不对 |

实验 3 排在最前面：它决定电池形态要不要改。

## 4 分工

- **设计方**：写规格、需求和设计文档；写生成原理图、板图、结构模型的脚本和固件；跑检查；整理测试结果。这部分主要由 AI 模型完成。
- **独立复核**：每道闸门由另一个模型（或人）独立检查一遍，不看设计方的结论，只看资料和产出。
- **需求方**：本项目的负责人。在闸门处拍板；下单付款（板子、贴片、电芯、散件）；启动打印；焊线和装配；按步骤实测并拍照。

设计方不下单、不启动打印机。

## 5 做法

- **电路**：原理图和板图由脚本生成（KiCad），同一份设计数据同时出原理图和板图。电源器件给明确坐标并做摆位检查，大电流走线和铺铜写进脚本，自动布线只管信号线。
- **结构**：用脚本建模（build123d），输出 STEP、STL、3MF；电路板从 KiCad 导出 STEP 一起做装配干涉检查。板框、接口、按键、灯板位置放在 [机电接口表](../interface/mech_elec.json) 里，电路脚本和结构脚本都读它。手机的原始尺寸来自苹果尺寸图，图纸带保密声明，原始尺寸只放在本地（格式见 [phone_template.json](../interface/phone_template.json)），不进仓库。
- **固件**：ESP-IDF 工程；纯逻辑部分在电脑上跑单元测试。
- **数字**：文档里的数字尽量由 `tools/` 下的脚本算出，改了假设可以重算。
- **打印**：外壳全部用熔融沉积打印机打印。灯头用耐热材料（ASA 或 ABS），其余用 PETG，贴手机的内衬用 TPU。先打试片再打整件。

## 6 出货前必须满足的检查

这几条是从以往只出图纸、没出实物的教训里来的：

1. 未连接数必须为 0，设计规则检查 0 错误。
2. 原理图与板图逐网络一致。
3. 物料清单的位号与贴片坐标文件的位号一致（测试点等不贴的器件不进物料清单）。
4. 电源器件的摆位按各自规格书的布局要求检查过。
5. 每颗关键器件的选型依据写明规格书页码。

## 7 流程指标（G9 复盘时统计）

- 每道闸门前被复核拦下的问题数，对比流到后面才发现的问题数。
- 改板次数、飞线数、打印迭代次数、板厂审核退回次数。
- 首板上电是否一次通过。
- 各阶段耗时。

见规格书第 8 节。

## 9 费用与时间（粗估）

- 费用约 1100–1700 元：三块板打样加贴片、电芯、散热片风扇等散件、实验用的物料和仪表、一卷耐热耗材。
- 时间约 4–5 周，其中一半以上是等物料、打板和打印。
