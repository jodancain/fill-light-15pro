# 机顶补光灯 · 结构草稿 v0.3

这是一套可重新生成的装配数模，不是可直接带电使用的定型外壳。尺寸与零件明细见 [核算报告](out/report.md)，基线取自 `interface/mech_elec.json`，本轮三板定义、孔位和局部叠层见 [PCB 交接](pcb/README.md)。手机使用公开外形；圆角和镜头平台均为示意，非苹果图纸数据。

## 生成与查看

在仓库根目录执行：

```sh
./mech/build.sh                       # 生成并回读 STEP / STL / GLB、四张 DXF、PNG 与报告
./mech/web.sh check --require-tcp     # JS、真实加载器，以及本机 TCP + curl 四项检查
./mech/web.sh serve 8000              # 只监听回环；Ctrl-C 停止
```

用浏览器访问 `http://127.0.0.1:8000/`。静态站点只需整个 `web/` 目录，原样放到 `/filllight/` 即可，无需改地址、联网或读取硬件工程。没有浏览器 GPU 或不允许监听时，`./mech/web.sh check` 仍能核对本地加载器、节点包络和标准库离线响应；这不等于实机渲染或 TCP 验收。

| 路径 | 用途 |
|---|---|
| [mech/pcb/](pcb/README.md) | PCB 画图工程师交付：三板和背视布局的 R2010 DXF / PNG、机器可读接口、整机 STEP。图纸和实体由同一份板坐标生成。 |
| `mech/board_layout.py`、`mech/pcb_draw.py` | 三板局部坐标、线序、禁布与限高；DXF 写入、实体读回、预览与交接说明。 |
| `mech/model.py` | 读取接口；自定结构参数、配合、几何与材料。 |
| `mech/export.py`、`mech/build.sh` | 用 Python 3.10+ 与 build123d、trimesh、ezdxf、matplotlib 构建（解释器用环境变量 `FL_PYTHON` 指定，未指定时依次尝试本机默认虚拟环境与 `python3`）；输出格式、量规、自检与重量共用一套实体。 |
| `mech/out/*.step`、`*.stl` | 同名文件是一种打印件；STEP 供改模，STL 为毫米网格。位置保留在装配坐标，切片时按下表旋转、放到平台，**不要镜像**。 |
| `mech/out/assembly.step` | 完整有名装配，含手机与非打印件，不应整件切片。 |
| `mech/coupons.py`、`mech/out/coupons/` | 三组试片，每组两个实体，均含 STEP / STL，不计入整机增重。 |
| `mech/out/files.md` | 按仓库相对路径列出的文件大小与校验值。 |
| `mech/out/report.md` | 外形、体积、质量、逐项结论及偏离。 |
| `web/models/filllight.glb`、`parts.json` | 分色可选零件、材料与尺寸、位移和标注；阵列灯珠分体建模、按暖白、冷白两组选择。 |
| `web/index.html`、`app.js`、`style.css`、`vendor/` | 查看页、交互、样式及带许可证的本地 three.js。 |
| `mech/web.sh`、`verify_web.py`、`check_glb.mjs` | 启动标准库 HTTP 服务、检查本地资源、用网页同版加载器复核 GLB。 |

**方向约定。** 接口、报告、量规均从手机背面看，x 右、y 下、z 朝被摄物，原点在左上角背玻璃面。这是左手描述。为避免打印出镜像件，制造文件统一用右手坐标 **(x, −y, z)**，单位 mm；GLB 采用同一物理方向，单位 m。核对方向时：背面朝眼睛、灯头在上，镜头示意台在左、颈部在右，USB-C 向下。

## 打印件与装配

| 零件 ID | 材料 | 建议摆放（拓竹 X2D） |
|---|---|---|
| `frame` | PETG | 背板平行平台，角唇或背部凸台择少量支撑；不要把支撑痕留在贴机面。 |
| `liner` | TPU | 背板外侧向下，四角软垫竖起。 |
| `neck` | PETG | 右侧长边向下，避免沿整个线槽搭顶；先确认端部小孔畅通。 |
| `head_shell` | ASA | 发光窗朝下。侧风槽、铜母座视切片预览加局部支撑。 |
| `head_bezel`、`head_grille` | ASA | 外侧平面向下，分别打印；后盖为进风格栅。 |
| `battery_tray` | PETG | 仓底朝下，侧窗桥接处局部支撑，清净滑轨。 |
| `battery_lid` | PETG | 三指滑盖底面平放，拨筋向上，勿让支撑或毛刺留在弹舌。 |
| `board_hood` | PETG | 按键面朝下，检查母座窗口顶面桥接。 |

建议先以 0.4 mm 喷嘴、0.2 mm 层高、至少三道约 0.4 mm 的外壁做试片，再看切片线宽、桥接和层间方向。除指定 1.0 mm 仓底，主体壁厚目标 1.2 mm；沉头用 45° 锥面，长矩形风窗并非全部免支撑。报告的重量按实体密度估算，不是切片耗材预测。

1. **壳架与颈部。** 装 TPU 衬，保证软面对手机、角唇与屏幕保留间隙。背板两只定位柱从下进入颈部；柱内装 M2 短热熔铜母，颈顶两颗沉头螺钉锁紧。Ø3.2 × 3 mm 为铜母试孔，不是通用采购尺寸。先在台面装铜母，降温后再靠近手机。
2. **接头与布线。** 颈顶端面对灯头底边，两个服务窗用短 M2 锁入灯头。两对双绞（每对一根 VSYS、一根 GND）和八根信号沿颈左侧走，不再平排交错。先走线再压端子；仓底贴背板；线束在颈下段平滑右移，从仓背局部脊盖下跨两芯到主板罩。样机须核包线外径、分线和压接后的弯折。
3. **光热叠层。** 将 2 mm 柔光片从发光侧嵌入台阶圈，外面齐平；灯板从后侧推至侧肩。四颗 M2.5 拧入散热器攻丝柱，小头及偏心的合成包络不得超 Ø4.0 mm，未定料；两侧压边留空。风扇四角锁入铝件，外框嵌入局部鳍片 2.2 mm；不得让叶轮擦鳍片。85°C 开关贴紧实铝接触面；热界面、夹具、温升均须实测。
4. **三板和开盖。** 驱动板 TOP 面朝风扇；M2 从后盖穿过 1.2 mm 承台与四个板孔，锁入壳体伸出的铜母肩，先在开壳状态插线。拆两只 M2，提起仓背脊盖和线束，再抽仓盖；滑盖沿 −x 抽开，沿 +x 推回扣合。七线经单独下端窗去主板。主板无安装孔，四底脚承托、罩内上压脚定位；两个 USB-C 朝 +y。裸板、焊脚、插合体和线端是不同的限界，不要将占位盒当采购料号。

## 试片顺序与未决项

| 先验证什么 | 怎么做 | 放行条件 |
|---|---|---|
| 四角夹持 | 先打 `corner_frame`（PETG）和 `corner_liner`（TPU），摆向同正式件，清理支撑，试装无保护壳手机。 | 单手可装取、不划伤；轻甩不脱，四边中段接口、键和收音可用。 |
| 单节仓位 | 打印 `one_cell_tray` / `one_cell_lid`（PETG，摆向同正式件），用敞开的单槽测压力、绝缘、滑轨与卡齿；再验证完整双仓。 | 最短及最长实芯都不晃、不伤皮；3 A 时每触点压降 ≤30 mV。 |
| 取景假件 | 打印 `view_head`（ASA）/ `view_pod`（PETG），两件均将封闭面朝平台；配合正式壳架、颈部，以端孔和可移胶临时定位到真实外廓；不要拿无厚度的轮廓线代替。 | 0.5×、1×、3× 均不入镜，逆光无光斑；另测风扇、电芯和线束对指南针、防抖的影响。 |

- 按本轮指定，仓底仅 1.0 mm，比通用最小打印壁薄 0.2 mm，但外仓厚仍为 23.4 mm；仓顶与侧窗的防护、印件误差、弹片行程和免工具换芯手感仍须实配。
- 不支持无线充电、MagSafe；使用本灯时关闭手机闪光灯。没有精确镜头、按键或传感器数据，也不以本模型证明光学或磁兼容。
- 散热与风道是几何预留，不是 20 W 温升验证。先用热假件测风量、灯板、电芯和外壳温度，再测试颈部 1 kg 侧向载荷（位移 ≤2 mm、不脱落）。
- 板上元器件、真实连接器、风扇叶片、弹片及刚性手机均为简化。核对驱动板最高元件与后盖/风扇的净空、胶层厚度和紧固工具空间；如不够，先评估提高灯头间距，而不是在 12 mm 间距下加深。静态零干涉不等于装配路径、热、强度或 G5 已通过。

**v0.3 试配重点。** `ridge.py` 定义截面、中心线与脊盖；`review03.py` 核分带和器件面积。`ridge_cover` 侧立打印，检查铜母、弯曲、七线独立出口以及在端子不拔出的情况下能否换芯。颈末与仓上沿为局部开式过渡；该段线束须压至 2.20 mm，不得磨破线皮。PETG 估重只适用于试配样；正式电池仓/主板罩按 HW-MEC-09 选有 V-0 声明的阻燃料并重新算重。
