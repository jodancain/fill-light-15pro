# 15 Pro 机顶补光灯

给 iPhone 15 Pro 定制的补光灯：灯头立在手机上方，两节 21700 和控制板在背面，外壳全部 3D 打印。做它是为了把一整条硬件开发流程真实走一遍：需求、选型、原理图、PCB、结构、固件、下单、装配、测试。

## 现在到哪一步

- G0 规格、G1 选型：文档已出第一版，**等需求方确认**。
- 还没做独立的设计复核（文档由一个 AI 模型单独写成）。上传前做过一轮发布检查，查的是泄露、保密和文档一致性，顺带修了查出的几处设计矛盾。
- 还没买任何东西，没画原理图。

两个角色：**需求方**是本项目的负责人，拍板、下单、打印、装配、实测；**设计方**写文档、脚本和固件，主要由 AI 模型完成。闸门 G0–G9 的定义见 [开发计划](docs/开发计划.md)。

## 脚本

文档里的推算数字由这三个脚本算出；器件参数来自原厂规格书。改了假设后要重跑脚本，再手动更新文档里的数字。

```bash
python3 tools/keepout.py      # 镜头和传感器禁入区 → 灯头、电池仓能放在哪
python3 tools/budget.py       # 续航、电流、充电时间、发热、重量、照度
python3 tools/hw_calc.py      # 灯驱动功率、测温分压、走线宽度、主控引脚
```

`keepout.py` 要用手机的原始尺寸。这些尺寸来自苹果尺寸图，图纸带保密声明，不放进仓库：从 <https://developer.apple.com/accessories/dimensional-drawings/> 下载 iPhone 15 Pro 的图纸，按 [interface/phone_template.json](interface/phone_template.json) 的格式填好，存为 `refs/iphone15pro.json`（`refs/` 不进仓库）。它算出的结果在 [interface/keepout.json](interface/keepout.json)，只含推导结果。

## 目录

```
docs/        文档
interface/   机电接口表、禁入区核算结果、手机尺寸数据的格式
tools/       核算脚本
refs/        本地资料（规格书、手机尺寸数据），不进仓库
```

以后会加 `hw/`（电路生成脚本和生成物）、`mech/`（结构建模脚本）、`fw/`（固件）、`review/`（各闸门的复核记录）。

## 安全

实验和测试涉及锂电池、短路和高温。只在有防护、有人看管时做，放在不易燃的台面上。文档是这个项目的设计记录，不是安全操作指南。
