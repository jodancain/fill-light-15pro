# 硬件需求

**v0.1 · 2026-11-17 · 依据 [规格书](规格书.md) v0.1、[系统架构说明书](系统架构说明书.md) v0.1、[硬件架构设计书](硬件架构设计书.md) v0.1**

本文件把规格书里已确认的决定和指标，转写成可以逐条验收的硬件要求，共 93 条。

## 0 读法

### 0.1 证据边界

文中所有数值都是**设计目标，未实测**。标了“核算”的数字来自 `tools/` 下的三个脚本（keepout、budget、hw_calc），其中的效率、热阻、电阻是估计值，要由实验和实测替换。器件能力引用的是原厂规格书的页码，没有在实物上复现。

本文件由一个 AI 模型单独写成，**没有做独立复核**。要补一轮由另一个模型或人做的复核，复核前不能当作冻结版本。

### 0.2 记号

| 记号 | 含义 |
|---|---|
| P0 | 必须：第一版样机必须满足 |
| P1 | 应该：尽量满足，达不到要记录原因并告知需求方 |
| P2 | 可选 |
| G0–G9 | 闸门，定义见[开发计划](开发计划.md)第 2 节；“闸门”列写的是在哪几道闸门验证 |

验证方法只用四类：**测试**（用仪表在实物上量）、**分析**（计算、预算、对照规格书）、**检查**（审图纸、清单、实物外观）、**演示**（在样机上操作，看功能是否出现）。

来源写法：“决定”指规格书第 2 节需求方确认的决定；“苹果图纸”指苹果官方 iPhone 15 Pro 尺寸图（2023-10-10）；“苹果指南”指苹果《配件设计指南》R32 Update 1（2026-10-30）；“BQ25798 第 x 页”“TPS61500 第 x 页”指 TI 规格书 SLUSDV2C、SLVS893F；“核算”指三个脚本的输出；“推导”指由上述来源推出、本项目自定的要求。

### 0.3 测试条件的限制

需求方手头只有烙铁和万用表，另备照度计、USB 功率表、测温表。需要示波器、可调电源、光谱仪才能测的项目，本文件改用能做到的办法（例如用手机高速快门查频闪），并在该条写明。
