# v0.5｜PCB 机械交接

C（外接电源）和 A（换包）均为机顶发光，驱动板和灯板只制作一套，板坐标不因整机平移而变。DXF 为 R2010/mm，BOARD_OUTLINE 导板边，孔、固定器件、连接器、两面禁区和限高各自分层。正视 TOP：u 向右、v 向上；装配 STEP 为 (X,−Y,Z)。不能按结构框造焊盘。

按 main / main_battery 区分主板，driver、led 图共用。assembly_layout[_battery] 和 enclosure_assembly[_battery].step 分别给 XY 与三维。两个 PCB 接口 JSON 的 harness 含 12 芯、电阻、两端板/整机坐标、插拔及高度。灯板五线、风扇和温控留在头内。
C 三键五灯在主板，A 在盖面用九线 J6。两个 USB-C 口均朝 +Y。Q_TIM 11×3.2，封装 +2.2、压垫 0.6，热量向外。A 六针 J5 每针 ≥5 A：BAT+、BAT+、MID、NTC、BAT−、BAT−，插合 ≤14.5 mm。C 为 8 V 稳压；A 为 BQ25798 系统电压，PD 表待电气侧给出。定版前请核对料号、公差、线材与接触电阻、保险和充电电流。

## 无孔灯板：压框与布线
四边各压 0.8 mm，四角让空；上下支撑防止薄板中跨翘起，侧边母线不必因压框改道。
|边|u (mm)|v (mm)|
|---|---|---|
|left|0–0.8|2–32|
|right|61.2–62|2–32|
|bottom|2–60|0–0.8|
|top|2–60|33.2–34|
绝缘 ASA 平压条（与灯头壳同料），平面均压于阻焊；允许阻焊完整覆盖的铜线，禁止露铜、焊盘、过孔。
W_P 可经过 u=0.3–0.8 的重叠区；该区不得开阻焊窗。
背面绝缘导热垫 0.50→0.40 mm（20%）；以超软垫在此压缩率的目标应力 10 kPa、约 2100 mm² 估算总力 21 N，四边按长度分配。须按采购垫压缩曲线、压敏纸及热循环后板翘复核，不是已测夹力。
